Espacio de administración

El taller.

Entrar a administrar

Acceso exclusivo para la persona autorizada en el repositorio de Oswood. Los visitantes no pueden subir ni modificar contenido.

Cómo habilitar el acceso por primera vez
  1. El administrador de paredesivan/Oswood debe dar acceso de escritura a la cuenta GitHub del carpintero.
  2. En esa cuenta, crear un fine-grained personal access token. Elegir el propietario paredesivan, únicamente el repositorio Oswood, y permiso Contents: Read and write. Si la cuenta invitada no permite elegir el repositorio, el propietario deberá emitir la credencial limitada a Oswood y entregarla de forma privada.
  3. Elegir una fecha de vencimiento y pegar la credencial aquí. Nunca subirla al repositorio ni compartirla con visitantes.

La credencial se usa solo en esta pestaña y se envía únicamente a la API de GitHub. Al recargar hay que volver a entrar. Una credencial con escritura también permite modificar archivos del repositorio: compartila solo con quien administre el sitio.

Contenido cargado

Los cambios se guardan al publicar. La web puede tardar unos minutos en actualizarse. Si cerrás esta pestaña antes de publicar, se pierden los cambios.
